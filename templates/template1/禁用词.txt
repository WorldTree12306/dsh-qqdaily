# 禁用词 / 屏蔽话题表
#
# 一行一个词。凡是**含有这些词的聊天记录行、素材、AI 写出来的条目**，
# 程序会整条丢掉，绝不会出现在报纸上（这是硬过滤，不是靠 AI 自觉）。
#
# 另外还有一条硬机制：**被这张表砸掉的消息，前后半小时算「禁区」**——
# 群主在那段时间里说的话，也不许拿来当头条。因为一条消息之所以被砸，
# 往往是因为那一整段对话都在讲不该上讲的事。
#
# 用途：
#   1) 群外人士的名字 —— 别的群的群友、群外认识的人。写在这里，报纸上就再也不会出现他。
#   2) 脏字、骂人的词 —— 出现在这一行的整条素材会被丢掉。
#   3) 屏蔽话题 —— 群主的私事、工作、家里事。报纸写的是这个群，不是她的单位。
#   4) 任何你不想在报纸上看到的词。
#
# 规矩：一行一个词，不要加标点；# 开头的行是注释，不生效。
# 改完直接生效，下一期出报就用新表，不用重启任何东西。
