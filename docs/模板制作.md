# 版式模板制作

一份报纸 = **内容 JSON**（每期不同）＋ **模板目录**（风格固定）。模板换掉，版式就换掉，内容不用动。

## 目录结构

```
templates/example/
  模板.json               槽位表：每版放什么、有哪些开关（人读 + 机器可读）
  禁用词.txt              命中即不登；整条消息作废
  程序/排特刊v3.py         排版器：JSON → HTML → PDF → 每版 PNG
  程序/报纸版面模板.html    版面结构 + CSS（真正决定长相的文件）
```

## 排版器怎么被调用

```
python <模板>/程序/排特刊v3.py --内容 <内容.json> --期号 012 \
    [--刊名 群日报] [--日期 "2026 年 10 月 16 日　星期五"] [--时段 "10-14 21:00 — 10-16 19:20"] \
    [--署名 "本报记者"] [--引题 "群内观察"] [--容量 1010] [--量块 N]
```

路径与浏览器由环境变量注入（插件/CLI 会按配置设好，手工跑时可自己设）：

| 变量 | 含义 | 默认 |
|---|---|---|
| `QQDAILY_BASE` | 素材基目录，内容 JSON 里的相对图片路径按它解析 | 排版器上级目录 |
| `QQDAILY_OUT` | 成品目录（HTML/PDF/版图） | `<BASE>/5-报纸成品` |
| `QQDAILY_TMP` | 临时目录（无头浏览器 profile、测高页） | `D:\ai\out` |
| `QQDAILY_EDGE` | 浏览器可执行文件 | 自动探测 Edge |
| `QQDAILY_TPL` | 版面模板 HTML | `<模板>/程序/报纸版面模板.html` |
| `QQDAILY_PAPER` | 刊名（成品文件名、报头） | 命令行 `--刊名` |
| `QQDAILY_BAN` | 禁用词表 | `<模板>/禁用词.txt` |

## 内容 JSON 的最小骨架

```jsonc
{
  "headline": { "kicker": "要闻", "title": "…", "subtitle": "——…", "body": ["段1", "段2"] },
  "chapters": [ { "kicker": "数码", "title": "…", "deck": "——…", "body": ["段1", "段2"] } ],
  "minis":   [ { "title": "…", "text": "…" } ],
  "quotes":  [ { "text": "…", "who": "群昵称", "when": "10-16 19:12" } ],
  "masthead": { "stance": "…", "face": "🐋", "tip": "…", "editor": "…", "editor_note": "…" },

  "p1_minis": [ { "title": "…", "text": "…" } ],       // 第 1 版版底钉条
  "p2_minis": [ … ],                                    // 第 2 版版底钉条
  "p2_side_minis": [ … ],                               // 第 2 版右列（横板时逐条排下来）
  "vlead_chapter": "<chapters 里某章标题，逐字一致>",     // 第 2 版竖排题栏用哪一章
  "vlead_mini": "<短刊标题>",                            // 第 2 版右上那条
  "vlead_mini_horiz": true,                             // true=横板，false/缺省=竖排
  "vlead_image": { "file": "吉祥物/素材库/报花.png", "caption": "…" },  // 报花
  "vlead_image_in_region": true,                        // true=排在中栏正文下面

  "p3_plan": {                                          // 第 3 版左右对开
    "left": ["<章节或短刊标题>"], "left_mid": ["<短刊>"], "left_bottom": ["<短刊>"],
    "right_seq": ["rule", "<章节>", "<短刊>"],            // 序列里写 "rule" = 显式插分隔线
    "right_lines": [ { "text": "…", "who": "…" } ],      // 右半顶部群友语录
    "right_align": "bottom"                              // 右半整体贴底
  },

  "p4_mid":  [ { "kind": "head", "title": "短刊 · …" }, { "kind": "mini", "title": "…", "text": "…" },
               { "kind": "statbox", "title": "本期发言统计", "rows": [["总发言", "2,633 条"]], "note": "口径…" },
               { "kind": "qa", "title": "答群友问", "asker": "…", "question": "…", "answerer": "…", "answer": "…" } ],
  "p4_minis": [ { "kind": "line", "text": "…", "who": "…" } ],   // 版底语录栏
  "p5_mid":  [ … ]                                               // 末版：短刊 + 语录 + 署名（kind:"line", credit:true）
}
```

### 版中块的块型

`head`（小标题条）·`mini`（短刊）·`line`（一句话，可带 `credit:true` 表示署名不计引语）·
`rule`（分隔线）·`statbox`（带框统计表：`rows` 为 `[[左,右],…]`）·`qa`（答群友问两行制）·
`pic`（图片条：`file` + `caption`）

> 分隔线不必自己写：渲染器在块型切换时会自动插一条；写了也会去重，不会叠成两条。

## 想改版式，动哪里

| 想改 | 动这个文件 | 怎么动 |
|---|---|---|
| 字体、字号、行距、栏宽 | `程序/报纸版面模板.html` 的 CSS | 改 `.chap-body`、`.vlead.v2`、`.mini` 等 |
| 报头样式 | 同上 | `.masthead`／`build_p1()` 在 `排特刊v3.py` |
| 每版容量（可排版高度） | 命令行 `--容量`（默认 1010px，版心 279mm≈1054px） | 太大了会溢出，太小会多出空版 |
| 竖排题栏字号 | `排特刊v3.py` 的 `_vtitle_style()` | 按字数分档：≤8→19pt／9-10→17.4pt／11-12→16pt |
| 报花高度 | CSS `.vlead .vpic.small img` | 默认 72px（再高会把下一章挤出版） |
| 禁用词 | `禁用词.txt` | 一行一个词；命中即整条不登 |

## 自检清单（换完模板后跑一遍）

```bash
python python/qqdaily.py check --期号 012
```

- 每版 **溢出 +0px**、**页脚间距 ≥6px**、**中部不留 >300px 空白**
- 引语 **逐字 100%**（未命中会点名）、禁用词 **0**
- 大章节 ≥8（含头条）、小章节 ≥12、语录/一句话 ≥8
- 出图后人工看一眼：版底钉条没压页脚、竖排区竖线拉到底、分隔线不重复
